준비 · Chapter 01

구글시트 연결과 권한 시트(관리자)

과제 입력은 구글시트의 「2026 추진현황」 같은 연도 탭을 읽고 씁니다. 누가 어떤 역할이고 팀마다 어느 시트를 쓰는지는 관리자가 관리 › 권한 시트에 적어 둡니다.

관리자
탭 이름「YYYY 추진현황」(예: 2026 추진현황)→연도 메뉴의 한 해
시트 공유입력하는 사람 계정에 추진현황 시트 편집 권한→구글시트에 저장 가능
권한 시트「성과관리 앱 권한 관리」 · 사용자 · 연결 시트 · 안내 탭→역할 · 팀별 추진현황 시트
운영 팀 시트연결해도 읽기만→저장 · 탭 만들기 안 함

관리 › 권한 시트

관리 · 권한 시트
1

추진현황 시트 준비

연도마다 「2026 추진현황」처럼 이름 붙인 탭을 둡니다. 입력할 팀원에게 이 시트의 편집 권한을 줍니다.

2

권한 관리 시트 만들기

사이드바 아래 관리(관리자만 보임) › 권한 시트에서 권한 관리 시트 만들기를 누릅니다. 내 구글 드라이브에 「성과관리 앱 권한 관리」 시트가 생기고, 지금 아는 관리자 · 팀장과 지금 연결된 추진현황 시트가 미리 들어갑니다. 이미 있는 권한 시트는 링크를 붙여 연결합니다.

3

앱에서 사람 · 역할 고치기

같은 화면의 사용자 표에서 칸을 눌러 이메일 · 이름 · 역할(관리자 / 팀장 / 팀원) · 팀 · 메모를 바로 고칩니다. 한 명 추가, 또는 여러 명 붙여넣기(한 줄에 「이메일, 이름, 팀」 · 아이디만 적으면 @gmail.com)로 넣습니다. 아래 연결 시트 표에서 팀별 추진현황 시트 링크도 고칩니다(팀을 전체로 적은 줄은 자기 팀 줄이 없는 모두가 씀).

4

구글시트에 저장

고치면 위에 저장 안 한 변경 N건 줄이 뜹니다. 구글시트에 저장을 누르면 바꾼 것 목록을 확인한 뒤 권한 시트에 쓰고, 시트의 「변경 기록」 탭에 시각 · 누가 · 바꾼 것을 한 줄 남깁니다. 고치는 사이 누가 시트를 직접 바꿨으면 덮어쓰지 않고 시트 내용을 다시 불러옵니다. 저장하려면 로그인한 관리자 계정이 권한 시트의 편집자여야 합니다.

5

팀원에게 공유하기

권한 관리 시트 열기 → 구글시트 오른쪽 위 공유에서 팀원에게 뷰어 권한을 줍니다. 추진현황 시트는 따로 공유해야 합니다. 앱 링크는 복사로 보내거나 팀원 초대 메일에 넣습니다.

관리자팀장이 하는 것 전부 + 관리 메뉴(권한 표 · 팀원 초대)→시트 연결 바꾸기(링크 · 새 연도 · 엑셀로 시작)
팀장과제 입력 + 성과관리(팀 · 평가 · 피어리뷰 · 면담)→시트는 불러오기만
팀원과제 입력만→추진현황 입력 · 저장 · 진척률 보기
로그인할 때 읽음모두의 앱이 로그인할 때 권한 시트를 읽어 메뉴(역할)와 추진현황의 관리자가 공유한 시트(내 팀 줄, 없으면 「전체」 줄)를 정합니다.
처음 관리자앱에 정해 둔 첫 관리자 계정은 권한 시트와 상관없이 늘 관리자입니다.
연결 끊기이 브라우저에서만 권한 시트 연결을 끊습니다. 시트는 그대로이고, 다른 권한 시트로 바꾸기로 다른 시트를 연결합니다.
팀원 초대관리 › 팀원 초대에서 Gmail로 초대 메일을 보냅니다. 메일 속 앱 주소 줄은 받은 메일에서 앱 바로 열기 버튼으로 보입니다.
시트 연결 설정관리자는 추진현황 머리 오른쪽 ⋯ › 시트 연결 설정…에서 이 브라우저가 쓸 시트를 바꿀 수 있습니다. 팀원은 같은 자리의 공유받은 시트 링크로 열기…를 씁니다.
구글 로그인 없이Google 연동 없이 시작하면 새 연도 만들기나 엑셀 파일로 시작하고, 이 브라우저에만 저장됩니다.
시작 · Chapter 02

로그인과 화면 둘러보기

로그인하면 홈에서 할 일을 고릅니다. 모든 이동은 왼쪽 사이드바(또는 위 메뉴)에서 합니다.

모두
홈
1

구글 계정으로 로그인

Google 계정으로 시작을 누르고 회사 구글 계정으로 로그인합니다. 이때 구글시트 읽기 · 쓰기 권한도 함께 받으므로, 불러오기 · 저장 때 권한 창이 따로 뜨지 않습니다. 이 브라우저에서 로그인 유지를 켜 두면 다음에는 이 계정으로 계속만 누릅니다.

2

왼쪽 사이드바

위에서부터 홈 · 과제 입력(추진현황 · 진척률) · 성과관리(프로젝트 목록 → 고른 프로젝트 이름 → 과제관리 · 팀원관리 · 평가하기 · 평가결과 · 면담, 팀장만)입니다. 아래에는 사용 매뉴얼, 데이터 백업(성과관리 안에서), 관리(관리자만), 계정 메뉴가 있습니다.

3

화면 머리(위치 줄)

「과제 입력 / 📁 2026 실적관리 ▾ / 추진현황」처럼 지금 위치가 보이고, 오른쪽 끝 ⋯에 파일 메뉴가 있습니다. 왼쪽 위 로고를 누르면 언제든 홈으로 갑니다.

4

메뉴 모양 바꾸기

머리 맨 앞 버튼(언제나 같은 자리)을 누를 때마다 펼침 → 아이콘만 → 위 메뉴 → 다시 펼침 순서로 바뀝니다. 아이콘만일 때는 마우스를 올리면 메뉴 이름이 보이고, 위 메뉴일 때는 사이드바 없이 머리 한 줄에 과제 입력 | 성과관리 전환 · 연도(평가기간) · 메뉴가 들어가 표를 가장 넓게 씁니다. 고른 모양은 이 브라우저에 기억됩니다.

5

역할 확인

사이드바 맨 아래 계정 이름 밑에 역할(관리자 · 팀장 / 팀장 / 팀원)이 보입니다. 팀원은 과제 입력만 씁니다. 로그아웃은 계정을 눌러 엽니다(위 메뉴일 때는 오른쪽 끝 동그라미).

위 메뉴 모양
매뉴얼사이드바 아래 사용 매뉴얼을 누르면 지금 화면에 맞는 장이 오른쪽에 열립니다. 홈 카드의 매뉴얼 버튼은 준비할 것부터 엽니다.

추진현황 시작하기

처음 추진현황을 열면 「추진현황을 시작하세요」 화면에서 관리자가 공유한 시트를 불러옵니다.

처음 한 번
과제 입력 · 추진현황을 시작하세요
1

관리자가 공유한 시트 확인

구글시트에서 불러오기 카드에 관리자가 공유한 시트가 「파일 이름 › 탭 이름」으로 보입니다. 이름 대신 링크만 보이면 시트 이름 확인을 누릅니다.

2

연결

「… 시트로 연결할까요?」 아래 연결을 누르면 연도 탭을 읽어 그룹(L1)마다 일정표를 만듭니다. 다른 시트를 공유받았다면 아니요, 공유받은 다른 링크 붙여넣기에 링크를 넣고 이 링크로 연결을 누릅니다.

3

관리자만: 다른 시작

엑셀 파일 열기(구글시트에서 xlsx로 받은 파일 · 보기 전용)나 새 연도 만들기로도 시작합니다. 팀원은 공유받은 구글시트로만 시작합니다.

최신 내용 받기

로그인할 때마다 연결된 시트를 자동으로 다시 읽어, 다른 팀원이 저장한 내용을 받아 옵니다. 새로 로그인하지 않고 앱을 다시 열었으면 머리 오른쪽에 최신 내용 안 받음 [받기] ✕가 뜹니다. 받기를 누르세요.

관리자가 공유한 시트권한 시트의 「연결 시트」 탭에서 내 팀 줄의 시트, 없으면 「전체」 줄의 시트입니다(과제 입력 매뉴얼 1장).
과제 입력 · Chapter 04

연도 메뉴와 ⋯ 파일 메뉴

머리의 「📁 2026 실적관리 ▾」에서는 연도만 고르고, 불러오기 · 엑셀 · 시트 연결은 오른쪽 끝 ⋯ 파일 메뉴에서 합니다.

연도별 1년
과제 입력 · 연도 메뉴
1

연결됨 · 편집

지금 입력하는 연도입니다. 여기서 고친 내용이 이 구글시트 탭에 저장됩니다.

2

보기 전용

지난 연도는 볼 수만 있습니다. 관리자는 연결하기로 그 탭을 입력하는 연도로 바꿉니다(입력하던 연도는 그대로 남아 다시 고를 수 있음).

3

이 브라우저 연도

앱에서 만든 연도는 이 브라우저로 표시되고 이 브라우저에 저장됩니다. 휴지통 아이콘으로 지웁니다.

4

목록에서 숨기기

쓰지 않는 연도에 마우스를 올리면 ×가 나옵니다. 목록에서만 빠지고 구글시트 탭은 그대로입니다. 메뉴 아래 숨긴 연도 n개 다시 보이기로 되돌립니다.

5

+ 새 연도 만들기

관리자에게만 보입니다. 다음 장을 보세요.

과제 입력 · ⋯ 파일 메뉴
구글시트 › 다시 불러오기연결된 시트를 다시 읽습니다. 오른쪽에 마지막으로 불러온 때가 보입니다.
구글시트 › 「시트 이름」 열기연결된 구글시트를 새 탭에서 엽니다.
구글시트 › 구글시트로 만들기이 브라우저 연도일 때(관리자) 연결된 시트에 이 연도 탭을 만들어 표를 통째로 씁니다. 그 뒤로는 시트와 연결됩니다.
엑셀 › 엑셀로 받기시트 모양 그대로(칸 색 · 메모 포함), 저장 안 한 변경까지 넣어 받습니다.
엑셀 › 엑셀 파일 열기관리자만. 구글시트에서 xlsx로 받은 파일을 봅니다(보기 전용).
시트 연결 설정…관리자는 어느 시트에 연결할지 바꿉니다. 팀원에게는 공유받은 시트 링크로 열기…로 보이고, 넣은 링크는 이 브라우저에 기억합니다.
도구 줄표 위 도구 줄에는 입력 도구만 있습니다. 불러오기 · 엑셀 · 시트 연결은 모두 ⋯ 파일 메뉴에서 합니다.
시트 탭 목록연도 메뉴를 열 때마다 구글시트의 탭 목록을 다시 읽습니다. 시트에서 지운 탭은 목록에서도 빠집니다.
과제 입력 · Chapter 05

새 연도 만들기(관리자)

지금 연도의 구성을 이어받거나 빈 표로 한 해를 시작하고, 어디에 둘지 고릅니다.

관리자
과제 입력 · 새 연도 만들기
1

연도

만들 연도를 고릅니다. 이미 있는 연도는 만들 수 없습니다.

2

시작 방법

이어받기는 그룹(L1) · 구분(L2) · 열 구성을 그대로 가져오고 주 칸(계획 · 실적)은 비웁니다. 과제는 완료 안 된 과제만 이월 / 과제 모두 / 구분만(과제 없이) 중에서 고릅니다. 빈 표로 시작은 기본 열과 첫 그룹(L1) 이름으로 시작합니다.

3

저장 위치

구글시트가 연결돼 있으면 구글시트(연결된 시트에 「YYYY 추진현황」 탭을 바로 만들기)와 이 브라우저(나중에 ⋯ › 구글시트로 만들기) 중에서 고릅니다.

과제 없이 시작하면빈 표나 구분만으로 시작하면 이 브라우저에 먼저 만듭니다(시트는 과제 이름이 있는 줄만 과제로 읽기 때문). 과제 이름을 넣은 뒤 ⋯ › 구글시트로 만들기를 누르세요.

추진현황 입력하기

그룹(L1) 탭별 일정표에서 과제와 일정을 입력합니다.

모두 입력
과제 입력 · 추진현황
1

입력하기

도구 줄의 입력하기를 누르면 입력 모드가 됩니다. 끝나면 입력 끝내기를 누릅니다.

2

칸 선택과 입력

한 번 누르면 선택, 더블클릭하거나 바로 타자를 치면 입력입니다. Enter 반영, Esc 취소. 여러 칸은 끌거나 Shift+클릭으로 고릅니다.

3

서식 막대

칸을 고르면 위에 서식 막대가 뜹니다. 글자색 · 크기 · 굵게 · 기울임 · 취소선 · 정렬 · 병합/나누기를 고른 칸 전체에 적용합니다.

입력 모드 · 서식 막대

일정 칠하기와 저장

주 칸에 계획과 실적을 칠하고, 구글시트에 저장해야 다른 팀원이 받아 볼 수 있습니다.

저장 필수
1

칠하기 도구 고르기

입력 모드에서 계획(회색) · 실적(분홍) · 지우개를 고르고 주 칸을 누르거나 끌어서 칠합니다. 도구를 우클릭하면 색 팔레트가 열립니다.

2

시작 · 끝 표시

칠한 묶음의 첫 주에 S가 찍히고, 계획이 끝나는 주에는 F가 자동으로 찍힙니다. 실적은 끝난 주 칸을 한 번 더 누르면 완이 찍히고, 다시 누르면 진행 중(글자 없음)으로 돌아갑니다.

3

저장 안 한 변경 확인

고친 칸에는 주황 점이 찍히고, 머리 오른쪽에 ● 저장 안 한 변경 N이 뜹니다. 고친 내용은 먼저 이 브라우저에만 쌓입니다. 되돌리기 ⌘/Ctrl+Z, 다시 하기 ⌘/Ctrl+Shift+Z.

머리 오른쪽 · 저장 안 한 변경
4

구글시트에 저장

알림의 구글시트에 저장(또는 입력 중 도구 줄 오른쪽의 같은 버튼)을 누르면 시트에 씁니다. 입력 끝내기를 누를 때 저장 안 한 변경이 있으면 저장 창이 바로 뜹니다.

5

알림 닫기 · 창 닫기

알림의 ✕는 알림만 숨기고, 변경 수가 바뀌면 다시 보입니다. 저장하지 않고 탭을 닫으려 하면 브라우저가 한 번 묻습니다.

6

엑셀로 받기 · 성과관리로 내보내기

⋯ › 엑셀로 받기로 지금 표를 받고, 팀장은 탭 줄 오른쪽 종이비행기 아이콘으로 그룹(L1)을 성과관리 과제리스트로 보냅니다.

저장해야 팀원이 봅니다저장하지 않은 고침은 내 브라우저에만 있습니다. 구글시트에 저장을 눌러야 다른 팀원이 불러오거나 로그인할 때 받아 볼 수 있습니다.
저장이 안 되면로그인한 계정이 그 구글시트의 편집자인지 확인하세요. 운영 중인 팀 시트와 엑셀 파일로 연 표는 시트에 저장하지 않습니다.

진척률

추진현황의 일정 칸으로 착수 · 완료를 자동으로 세고, 구글시트에 저장하거나 PPT · 엑셀로 받습니다.

자동 집계
과제 입력 · 진척률
합산[중점] 구분 + 일반업무 실적→연구소 전체 요약
실별구분(L2) 한 줄씩 + 소계→실마다 상세
칸과제계획 · 착수 · 현재 진행중 · 완료→달성률 · 진척률
1

기준 주 고르기

오른쪽 위 기준 주에서 어느 주까지 셀지 고릅니다(기본은 이번 주). 숫자 칸을 더블클릭하면 고칠 수 있고, 우클릭하면 그 칸의 과제 목록을 보거나 자동값으로 되돌립니다.

2

구글시트에 저장

구글시트에 저장을 누르면 저장할 곳(「디자인연구소 추진현황 › 2026 진척률」처럼 같은 파일의 진척률 탭)을 확인한 뒤 씁니다. 합산과 실별 표가 한 탭에 위아래로 들어가고, 탭이 없으면 새로 만들며 이미 있으면 내용을 지금 표로 바꿉니다. 저장하면 시트에서 열기 링크가 나옵니다. 팀원은 시트에서 같은 표를 봅니다.

3

다운로드 · PPT

다운로드 › PPT는 미리보기에서 넣을 탭을 골라 탭마다 한 장(16:9)으로 받습니다.

4

다운로드 · 엑셀

다운로드 › 엑셀은 표마다 시트 한 장(합산 · 실 이름)으로 받습니다. 화면과 같은 색(머리글 파랑 · 실적 분홍 · 합계 회색)입니다.

진척률 › 다운로드
저장되는 숫자고친 숫자도 그대로 저장 · 다운로드됩니다. 고친 숫자 자체는 이 브라우저에만 기억되므로, 팀과 맞춘 값은 구글시트에 저장으로 남겨 두세요. 구글시트에 연결되지 않은 연도(엑셀로 연 표 · 이 브라우저 연도)는 다운로드만 됩니다.

도움말 · Chapter 10

자주 묻는 질문

막혔을 때 먼저 확인하세요.

다른 팀원이 고친 내용이 안 보여요.

그 팀원이 구글시트에 저장까지 했는지 확인하세요. 저장된 내용은 로그인할 때 자동으로 받고, 머리의 최신 내용 안 받음 › 받기나 ⋯ › 다시 불러오기로도 받습니다.

저장하면 편집 권한이 없다고 나와요.

로그인한 계정이 그 구글시트의 편집자가 아닙니다. 시트 소유자에게 편집 권한을 요청하세요.

구글시트에 저장 버튼이 없어요.

운영 팀 시트가 연결돼 있으면 저장하지 않습니다(읽기 전용). 관리자가 ⋯ › 시트 연결 설정…에서 입력할 시트를 연결합니다. 엑셀 파일로 연 표도 시트에 저장하지 않습니다.

새 연도 만들기 · 관리 메뉴가 안 보여요.

관리자에게만 보입니다. 역할은 관리자가 권한 시트의 「사용자」 탭에서 정합니다.

구글시트에서 탭을 지웠는데 연도 목록에 남아 있어요.

연도 메뉴를 다시 열면 시트 목록을 새로 읽어 빠집니다. 탭은 남겨 두고 목록에서만 빼려면 그 연도의 ×를 누르세요.

화면이 하얗게 나와요.

새 버전이 올라온 직후일 수 있습니다. ⌘/Ctrl+Shift+R로 강력 새로고침하세요.

구글 로그인 창에 「400 · That’s an error」가 떠요.

브라우저에 구글 계정이 여러 개 로그인돼 있을 때 생깁니다. 계정 골라서 다시 로그인을 눌러 계정을 직접 고르세요.

검색 결과가 없습니다.
