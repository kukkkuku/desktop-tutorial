준비 · Chapter 01

구글시트 연결

과제 입력은 구글시트의 「2026 추진현황」 같은 연도 탭을 읽고 씁니다. 어떤 시트를 쓸지는 관리자가 정합니다.

관리자
탭 이름「YYYY 추진현황」(예: 2026 추진현황)→연도 메뉴의 한 해
권한입력하는 사람 계정에 그 시트 편집 권한→구글시트에 저장 가능
운영 팀 시트연결해도 읽기만→저장 · 탭 만들기 안 함
1

시트 준비

연도마다 「2026 추진현황」처럼 이름 붙인 탭을 둡니다. 입력할 팀원에게 시트 편집 권한을 줍니다.

2

시트 바꾸기

처음 화면 「추진현황을 불러오세요」 아래, 또는 연도 메뉴 맨 아래의 시트 바꾸기를 누르고 구글시트 링크를 붙여 연결합니다. 기본은 운영 시트의 사본인 테스트 시트이고, 기본 테스트 시트로 되돌리기로 돌아갑니다.

3

불러오기

구글시트에서 불러오기를 누르면 연도 탭을 읽어 그룹(L1)마다 일정표를 만듭니다.

4

저장

고친 칸에는 주황 점이 찍히고 「변경 N」이 늘어납니다. 구글시트에 저장을 누르면 시트에 씁니다. 처음 한 번은 구글시트 편집 권한을 허용합니다.

팀원시트 연결은 관리자가 정합니다. 팀원은 연결된 시트를 불러와 입력하고 저장합니다.
구글 로그인 없이Google 연동 없이 시작하면 새 연도 만들기나 xlsx 올리기로 시작하고, 이 브라우저에 저장됩니다. 관리자는 나중에 구글시트로 만들기로 시트에 탭을 만듭니다.
시작 · Chapter 02

로그인하고 할 일 고르기

로그인하면 홈에서 과제 입력 카드를 누릅니다. 머리글 맨 왼쪽 홈 버튼으로 언제든 돌아옵니다.

모두
홈
1

구글 계정으로 로그인

Google 계정으로 시작을 누르고 회사 구글 계정으로 로그인합니다. 이 브라우저에서 로그인 유지를 켜 두면 다음에는 이 계정으로 계속만 누릅니다.

2

과제 입력 카드

지금 연도 · 시트 · 과제 수 · 저장 안 한 고침이 보입니다. 이어서 입력하기(처음이면 시작하기)를 누릅니다.

3

역할 확인

계정 옆 배지가 팀원이면 과제 입력만, 관리자 · 팀장이면 성과관리도 보입니다.

매뉴얼머리글의 책 아이콘을 누르면 지금 화면에 맞는 장이 오른쪽에 열립니다.
과제 입력 · Chapter 03

연도 고르기

머리글의 「2026 실적관리 ▾」에서 입력할 연도와 지난 연도를 고릅니다.

연도별 1년
과제 입력 · 연도 메뉴
1

연결됨 · 편집

지금 입력하는 연도입니다. 여기서 고친 내용이 이 구글시트 탭에 저장됩니다.

2

보기 전용

지난 연도는 볼 수만 있습니다. 관리자는 연결하기로 그 탭을 입력하는 연도로 바꿀 수 있습니다.

3

새 연도 만들기

지금 연도의 그룹(L1) · 구분(L2) · 열 구성을 이어받거나(완료 안 된 과제만 / 과제 모두 / 구분만) 빈 표로 시작합니다. 만든 연도는 이 브라우저에 저장되고, 관리자가 구글시트로 만들기로 시트에 탭을 만듭니다.

4

목록에서 지우기

쓰지 않는 연도에 마우스를 올리면 ×가 나옵니다. 목록에서만 빠지고 구글시트 탭은 그대로입니다. 메뉴 아래 숨긴 연도 n개 다시 보이기로 되돌립니다.

시트 탭 목록메뉴를 열 때마다 구글시트의 탭 목록을 다시 읽습니다. 시트에서 지운 탭은 목록에서도 빠집니다.
과제 입력 · Chapter 04

추진현황 입력하기

그룹(L1) 탭별 일정표에서 과제와 일정을 입력하고 구글시트에 저장합니다.

모두 입력
과제 입력 · 추진현황
1

입력하기

도구 줄의 파란 입력하기를 누르면 입력 모드가 됩니다. 끝나면 입력 끝내기를 누릅니다.

2

칸 선택과 입력

한 번 누르면 선택, 더블클릭하거나 바로 타자를 치면 입력입니다. Enter 반영, Esc 취소. 여러 칸은 끌거나 Shift+클릭으로 고릅니다.

3

서식 막대

칸을 고르면 위에 서식 막대가 뜹니다. 글자색 · 크기 · 굵게 · 기울임 · 취소선 · 정렬 · 병합/나누기를 고른 칸 전체에 적용합니다.

입력 모드 · 서식 막대
분류 · 상태칸을 누르면 칩 목록에서 골라 넣습니다.
채우기고른 칸 오른쪽 아래 점을 끌면 엑셀처럼 반복 입력됩니다.
복사 · 붙여넣기⌘/Ctrl+C ⌘/Ctrl+V. 엑셀 · 구글시트에서 여러 칸을 복사해 와도 됩니다.
우클릭 메뉴행 · 열 추가/삭제, 칸 색, 서식 지우기, 병합 등. 병합하면 칸마다 적힌 글을 줄을 바꿔 이어 한 칸에 넣습니다(같은 글은 한 번만).
구분(L2) 칸클릭하면 선택, 더블클릭이나 Enter로 이름 고치기. 「이름 [중점]」처럼 쓰면 태그가 붙습니다.
과제 · 그룹 · 열 추가행 번호 아래 파란 + 로 과제, 탭 줄의 그룹 추가로 그룹(L1), 표 끝 + 열로 입력 열을 만듭니다.
행 옮기기행 번호를 누르면 표 왼쪽 밖에 손잡이(⋮⋮)가 생깁니다. 끌면 과제 이름이 마우스를 따라오고, 놓일 자리에 주황 선이 보입니다. 같은 구분(L2) 안에서만 옮깁니다.
행 높이 · 열 폭칸 경계를 끌어 조절하고, 행 경계를 더블클릭하면 자동 높이입니다. 행 우클릭 모든 행을 이 행 높이로로 한 번에 맞춥니다. ⌘/Ctrl+Z로 되돌립니다.
일정 폭12월 마지막 주 바깥 선을 끌면 모든 주 칸이 똑같이 늘고 줍니다.
선택 풀기표 밖 빈 곳을 누르면 칸 · 행 선택이 풀립니다.
과제 입력 · Chapter 05

일정 칠하기와 저장

주 칸에 계획과 실적을 칠하면 진척률이 자동으로 계산됩니다.

진척률 기준
1

칠하기 도구 고르기

입력 모드에서 계획(회색) · 실적(분홍) · 지우개를 고르고 주 칸을 누르거나 끌어서 칠합니다. 도구를 우클릭하면 색 팔레트가 열립니다.

2

시작 · 끝 표시

칠한 묶음의 첫 주에 S가 찍히고, 계획이 끝나는 주에는 F가 자동으로 찍힙니다. 실적은 끝난 주 칸을 한 번 더 누르면 완이 찍히고, 다시 누르면 진행 중(글자 없음)으로 돌아갑니다.

3

구글시트에 저장

고친 내용은 먼저 이 브라우저에 쌓이고, 구글시트에 저장을 눌러야 시트에 들어갑니다. 되돌리기 ⌘/Ctrl+Z, 다시 하기 ⌘/Ctrl+Shift+Z.

4

엑셀로 받기 · 성과관리로 내보내기

엑셀 아이콘으로 지금 표를 받고, 팀장은 종이비행기 아이콘으로 그룹(L1)을 성과관리 과제리스트로 보냅니다.

저장이 안 되면로그인한 계정이 그 구글시트의 편집자인지 확인하세요. 운영 중인 팀 시트에는 저장하지 않습니다.

도움말 · Chapter 08

자주 묻는 질문

막혔을 때 먼저 확인하세요.

저장하면 편집 권한이 없다고 나와요.

로그인한 계정이 그 구글시트의 편집자가 아닙니다. 시트 소유자에게 편집 권한을 요청하세요.

구글시트에 저장 버튼이 눌리지 않아요.

운영 팀 시트가 연결돼 있으면 저장하지 않습니다(읽기 전용). 관리자가 시트 바꾸기로 입력할 시트를 연결합니다. xlsx로 올린 표도 시트에 저장하지 않습니다.

구글시트에서 탭을 지웠는데 연도 목록에 남아 있어요.

연도 메뉴를 다시 열면 시트 목록을 새로 읽어 빠집니다. 탭은 남겨 두고 목록에서만 빼려면 그 연도의 ×를 누르세요.

화면이 하얗게 나와요.

새 버전이 올라온 직후일 수 있습니다. ⌘/Ctrl+Shift+R로 강력 새로고침하세요.

구글 로그인 창에 「400 · That’s an error」가 떠요.

브라우저에 구글 계정이 여러 개 로그인돼 있을 때 생깁니다. 계정 골라서 다시 로그인을 눌러 계정을 직접 고르세요.

검색 결과가 없습니다.
