연구소 전체가 한 해 동안 함께 쓰는 과제 입력(추진현황 · 진척률)과, 팀장이 반기마다 운영하는 성과관리(평가 · 피어리뷰 · 면담)를 한 앱에서 합니다. 팀원은 과제 입력만 쓰고, 성과관리는 팀장에게만 보입니다.

로그인과 홈 모두

  1. 앱 주소를 열고 Google 계정으로 시작을 누릅니다. 회사에서 받은 구글 계정으로 로그인합니다.
  2. 처음 쓰는 계정이면 구글이 권한 동의 화면을 띄웁니다. 앱이 구글시트를 읽고 저장하려면 허용해야 합니다.
  3. 로그인하면 홈이 열립니다. 카드를 눌러 할 일로 들어갑니다.
과제 입력 카드지금 연도, 연결된 시트, 과제 수, 저장 안 한 고침이 몇 건인지 보여 줍니다. 누르면 추진현황으로 갑니다.
성과관리 카드 (팀장)최근 프로젝트를 누르면 바로 들어가고, 아래 링크로 프로젝트 목록이나 팀 만들기로 갑니다.

어느 화면에서든 머리글 맨 왼쪽의 홈 버튼(집 모양)을 누르면 홈으로 돌아옵니다. 팀장은 그 옆의 과제 입력 성과관리로 두 영역을 바로 오갈 수 있습니다.

새로고침해도 괜찮습니다보던 화면에 그대로 머뭅니다. 새 창에서 열면 홈부터 시작합니다.

역할별로 할 수 있는 일

역할은 로그인한 구글 계정으로 정해지고, 머리글 오른쪽 계정 옆에 배지(팀원 / 관리자 · 팀장)로 보입니다. 시트를 실제로 고칠 수 있는지는 구글시트의 공유 권한(편집자)이 정합니다.

연도 고르기 과제 입력

머리글의 2026 실적관리 ▾를 누르면 연도 메뉴가 열립니다. 메뉴를 열 때마다 구글시트의 탭 목록을 다시 읽어서, 시트에서 지운 탭은 목록에서도 빠집니다.

  • 연결됨 · 편집: 지금 입력하는 연도입니다. 여기서 고친 내용이 이 탭에 저장됩니다.
  • 보기 전용: 지난 연도입니다. 눌러서 볼 수 있지만 고칠 수는 없습니다. 관리자는 연결하기로 그 탭을 입력하는 연도로 바꿀 수 있습니다.
  • 이 브라우저: 구글시트 없이 이 화면에서 만든 연도입니다. 휴지통 아이콘으로 지울 수 있습니다.
  • 목록에서 지우기: 쓰지 않는 연도에 마우스를 올리면 오른쪽에 ×가 나옵니다. 목록에서만 빠지고 구글시트 탭은 그대로입니다. 메뉴 아래 숨긴 연도 n개 다시 보이기로 되돌립니다.

새 연도 만들기

  1. 연도 메뉴에서 + 새 연도 만들기를 누릅니다.
  2. 연도를 고르고 시작 방법을 정합니다. 이어받기는 지금 연도의 그룹(L1) · 구분(L2) · 열 구성을 가져오고, 과제는 완료 안 된 과제만 / 과제 모두 / 구분만 중에서 고릅니다. 빈 표로 시작은 기본 열로 새로 만듭니다.
  3. 만든 표는 이 브라우저에 저장됩니다. 연구소가 함께 쓰려면 관리자가 구글시트로 만들기로 시트에 탭을 만듭니다.

추진현황 보기 과제 입력

  • 그룹(L1) 탭: 표 위의 탭으로 그룹을 바꿉니다. 보기 아이콘으로 보이는 그룹을 켜고 끕니다.
  • 찾기: 검색 칸에 L2 · L3 · 담당자 이름을 넣으면 해당 줄만 남습니다. 머리글을 눌러 칸별로 거를 수도 있습니다.
  • 글자 · 행간: 도구 줄의 글자 작게 · 크게 버튼으로 표 글자 크기를, 행간 버튼으로 줄 간격을 바꿉니다. 행 아래 경계를 끌면 그 행 높이만 바뀌고, 더블클릭하면 자동 높이로 돌아갑니다.
  • 일정 접기: 일정 머리글을 우클릭하면 보이는 기간을 바꿀 수 있습니다.

추진현황 입력하기 과제 입력

  1. 도구 줄 오른쪽의 파란 입력하기를 누르면 입력 모드가 됩니다. 끝나면 입력 끝내기를 누릅니다.
  2. 칸을 한 번 누르면 선택, 더블클릭하거나 바로 타자를 치면 입력이 됩니다. Enter로 반영하고 Esc로 취소합니다.
  3. 여러 칸은 끌거나 Shift+클릭으로 고릅니다. 행 번호를 누르면 행 전체, 열 머리글을 누르면 열 전체가 선택됩니다.

입력 중에 쓰는 기능

  • 서식 막대: 칸을 고르면 위에 뜹니다. 글자 색 · 글자 크기 · 굵게 ⌘/Ctrl+B · 기울임 ⌘/Ctrl+I · 취소선 · 정렬 · 병합 / 나누기 · ✓(선택 끝내기).
  • 분류 · 상태: 칸을 누르면 칩 목록이 열려 골라 넣습니다.
  • 채우기: 고른 칸 오른쪽 아래의 작은 점을 끌면 엑셀처럼 같은 값이 반복해 채워집니다.
  • 복사 · 붙여넣기: ⌘/Ctrl+C · ⌘/Ctrl+V. 엑셀이나 구글시트에서 여러 칸을 복사해 붙여넣어도 됩니다.
  • 우클릭 메뉴: 칸 · 행 · 열 · 구분마다 행 추가 · 삭제, 열 추가 · 삭제, 칸 색, 서식 지우기, 병합 같은 메뉴가 나옵니다.
  • 구분(L2) 칸: 클릭하면 선택되고, 더블클릭하거나 Enter를 누르면 이름을 고칩니다. 이름 [중점]처럼 쓰면 [중점] 태그가 붙습니다. 마우스를 올리면 아래에 구분 추가 · 삭제 아이콘이 나옵니다.
  • 과제 추가: 행 번호 오른쪽 아래의 파란 + 를 누르면 그 행 아래에 과제가 생깁니다. 그룹은 탭 줄의 그룹 추가로 만듭니다.
  • + 열: 표 오른쪽 끝에서 새 입력 열을 만듭니다.

일정 칠하기 과제 입력

주 칸(월별 주차)에 계획과 실적을 칠합니다. 입력 모드에서 도구 줄에 칠하기 도구가 나옵니다.

  • 계획(회색) 칠하기 · 실적(분홍) 칠하기 · 지우개: 도구를 고르고 주 칸을 누르거나 끌어서 칠합니다. 도구를 우클릭하면 색 팔레트가 열립니다.
  • 계획이 끝나는 주에는 F, 실적이 끝나는 주에는 완이 자동으로 찍힙니다.
  • 입력 모드가 아닐 때도 주 칸을 골라 복사 · 붙여넣기할 수 있고, 고른 칸 오른쪽 아래 점을 끌면 같은 모양으로 채워집니다.
진척률이 이 칠하기로 계산됩니다계획(회색)이 없는 과제는 실적(분홍) 시점을 계획으로 봅니다. 착수와 완료 주를 정확히 칠해 두면 진척률이 맞게 나옵니다.

저장 · 되돌리기 · 받기 과제 입력

  • 구글시트에 저장: 고친 내용은 먼저 이 브라우저에 쌓이고, 저장 버튼을 눌러야 구글시트에 들어갑니다. 저장 전에는 홈 카드에 "저장 안 한 고침 n건"이 보입니다.
  • 되돌리기 · 다시 하기: ⌘/Ctrl+Z · ⌘/Ctrl+Shift+Z. 저장하기 전의 고침은 모두 되돌리기로 한 번에 버릴 수 있습니다.
  • 엑셀 파일로 받기: 지금 보이는 표를 추진현황 기본 모양(맑은 고딕 8pt)의 엑셀로 받습니다.
  • 성과관리로 내보내기 팀장: 그룹(L1)을 골라 성과관리 프로젝트의 과제리스트로 보냅니다.
저장이 안 되면로그인한 계정이 그 구글시트의 편집자인지 확인하세요. 여러 사람이 같은 연도를 고친다면 입력 전에 시트를 새로 불러오는 것이 안전합니다.

진척률 과제 입력

머리글의 진척률을 누르면 추진현황의 일정 칸으로 자동 계산한 표가 나옵니다. 연도는 추진현황과 같이 움직입니다.

  • 합산 탭: [중점] 구분과 일반업무 실적을 모아 봅니다.
  • 실별 탭: 실마다 구분(L2) 한 줄씩과 소계를 봅니다.
  • 칸: 과제계획 · 착수(계획 · 실적 · 달성률) · 현재 진행중 · 완료(계획 · 실적 · 진척률).
  • 숫자 고치기: 숫자 칸을 더블클릭하면 고칠 수 있습니다. 고친 값은 이 브라우저에만 기억됩니다. 우클릭하면 해당 과제 목록을 보거나 자동값으로 되돌립니다.
  • PPT로 내보내기 · 미리보기: 탭마다 한 장씩, 미리보기에서 고른 탭만 PPT로 받습니다.

프로젝트 만들기 팀장

  1. 홈에서 성과관리 카드의 팀 만들기(또는 프로젝트 목록)를 누릅니다.
  2. 팀 이름을 넣고 다음 → 평가기간(연도 · 상반기/하반기)을 골라 평가 만들기를 누릅니다.
  3. 이후에는 머리글의 프로젝트 이름 ▾로 다른 프로젝트로 바꿉니다. 프로젝트 카드를 우클릭하면 복제하거나 지울 수 있습니다.

과제관리 팀장

과제리스트

  • 추진현황에서 가져오기: 과제 입력의 표에서 필요한 구분(L2)만 골라 가져옵니다. 과제 입력의 성과관리로 내보내기와 같은 화면입니다.
  • 구글시트에서 가져오기 · L2 직접 만들기도 됩니다.
  • L3 과제를 체크하고 평가과제로 내보내기를 누르면 평가과제가 생깁니다. 여러 줄을 체크해 평가과제로 묶기로 하나로 묶을 수 있습니다.

평가과제

  • 과제등급 · 성과등급 · 목표 · 성과를 표에서 바로 입력합니다. 점수와 참여 인원은 자동으로 계산됩니다.
  • 과제명 앞의 ›를 누르면 묶인 L3가 회색 줄로 펼쳐집니다(그룹 · 과제 · 상태 · 담당자 · 기간).
  • 여러 행을 골라 우클릭하면 묶거나 풉니다.

팀원관리 팀장

  • 팀원: 칸을 눌러 바로 입력하고, 표 아래 팀원 추가로 줄을 늘립니다. 엑셀에서 여러 줄을 복사해 붙여넣어도 됩니다.
  • 인사기록 불러오기: 인사기록 파일에서 입사일 · 직급 같은 정보를 채웁니다.
  • 팀원 초대 관리자: 팀원에게 앱 사용 안내 메일을 보냅니다.
팀원을 지우면그 팀원의 기여도 · 피어리뷰 · 면담 기록도 함께 지워집니다. 바로 ⌘/Ctrl+Z로 되돌릴 수 있습니다.

피어리뷰 (엑셀) 팀장

팀원관리 › 피어리뷰에서 합니다. 팀원은 앱에 들어오지 않고, 팀장이 나눠 준 엑셀 양식에 적어 돌려줍니다. 단순 순위(팀원 전체, 본인 제외)와 과제별(함께한 평가과제마다) 두 방식이 있습니다.

  1. 엑셀 양식 받기를 누르면 팀원별 양식이 ZIP으로 내려받아집니다.
  2. 각자에게 자기 파일을 메일이나 메신저로 보냅니다.
  3. 팀원은 다른 팀원에게 1위부터 순위를 겹치지 않게 매기고, 사람마다 순위 근거를 꼭 적어 돌려줍니다.
  4. 받은 파일을 엑셀 올리기로 한꺼번에 올립니다(여러 개 선택 가능). 순위가 겹치거나 근거가 빠진 파일은 반영하지 않고 이유를 보여 줍니다.
  5. 위쪽 응답 현황 n/N명에서 누가 냈는지 봅니다. 파일을 못 받은 사람은 이름을 눌러 팀장이 직접 입력할 수 있습니다.
  6. 아래 피어리뷰 결과에서 대상자별 평균 순위와 근거를 봅니다. 점수 반영 비율은 기준설정의 피어리뷰에서 정합니다.

평가 · 결과 · 면담 팀장

  • 평가하기: 평가과제마다 팀원의 기여도를 넣습니다.
  • 평가결과: 등급 · 기여도 · 피어리뷰(반영 비율을 켠 경우)를 합친 점수와 순위를 봅니다.
  • 면담: 팀원별 면담 기록을 남깁니다.

데이터 백업 · 초기화 팀장

성과관리 데이터는 팀장의 브라우저와 구글 드라이브에 저장됩니다. 머리글의 데이터 백업에서 관리합니다.

  • 로컬 파일: JSON(복원용 원본) · 엑셀(보관용 사본)로 내려받습니다.
  • Google Drive: 드라이브에 저장하고 다른 기기에서 불러옵니다.
  • 데이터 초기화: 이 브라우저만 또는 Drive 포함 전체를 지웁니다. 과제 입력 데이터도 같이 지우기를 체크하면 이 브라우저에 저장된 추진현황 · 저장 안 한 고침 · 만든 연도 · 진척률 수정값도 지웁니다. 구글시트와 연결 설정은 그대로입니다.

구글시트에서 탭을 지웠는데 연도 목록에 남아 있어요.
연도 메뉴를 다시 열면 시트 목록을 새로 읽어 빠집니다. 탭은 남겨 두고 목록에서만 빼려면 그 연도의 ×를 누르세요.
화면이 하얗게 나와요.
새 버전이 올라온 직후일 수 있습니다. ⌘/Ctrl+Shift+R로 강력 새로고침하세요.
구글 로그인 창에 "400 · That's an error"가 떠요.
브라우저에 구글 계정이 여러 개 로그인돼 있을 때 생깁니다. 오류 안내 아래의 계정 골라서 다시 연결을 눌러 계정을 직접 고르세요.
저장하면 "편집할 권한이 없습니다"라고 나와요.
로그인한 계정이 그 구글시트의 편집자가 아닙니다. 시트 소유자에게 편집 권한을 요청하세요.
성과관리가 안 보여요.
성과관리는 팀장 계정에만 보입니다. 머리글 계정 옆 배지가 "팀원"이면 과제 입력만 쓸 수 있습니다.
성과관리를 초기화했는데 과제 입력에 예전 표가 그대로 보여요.
두 영역의 데이터는 따로 저장됩니다. 초기화할 때 과제 입력 데이터도 같이 지우기를 체크하세요.
