어떤 일을 하시나요?

과제 입력은 연구소 모두가, 성과관리는 팀장이 씁니다. 각 매뉴얼은 준비할 데이터부터 순서대로 안내합니다.

과제 입력 매뉴얼

권한 시트 · 구글시트 연결(관리자) → 로그인 → 공유된 시트 불러오기 → 연도 · ⋯ 파일 메뉴 → 추진현황 입력 · 일정 칠하기 · 구글시트에 저장 → 진척률

성과관리 매뉴얼

준비(과제 가져올 곳 · 인사기록카드 · 이전 성과) → 프로젝트 · 새 평가 시작 → 과제관리(평가 대상 · 성과등급 · 목표/성과) → 피어리뷰 · 평가하기 → 평가결과 · 리포트 → 승진 시뮬레이션 · 면담 · 데이터 백업

화면의 인물·과제·조직 정보는 모두 설명용 가상 데이터입니다.
