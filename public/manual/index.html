Chapter 01

로그인과 홈

홈에서 할 일을 고르고, 머리글 맨 왼쪽 홈 버튼으로 언제든 돌아옵니다.

모두
홈
팀원

과제 입력만

추진현황 입력, 진척률 보기, 새 연도 만들기. 성과관리는 보이지 않습니다.

팀장

과제 입력 + 성과관리

프로젝트 · 평가과제 · 팀원 · 피어리뷰 · 평가 · 면담을 운영합니다. 머리글에서 두 영역을 바로 오갑니다.

관리

관리자

과제 입력이 쓰는 구글시트를 연결하고, 연도 탭을 시트에 만들고, 팀원을 초대합니다.

1

구글 계정으로 로그인

Google 계정으로 시작을 누르고 회사 구글 계정으로 로그인합니다. 처음이면 구글시트 읽기 · 저장 권한을 허용합니다.

2

홈에서 카드 고르기

과제 입력 카드에는 지금 연도 · 시트 · 과제 수 · 저장 안 한 고침이, 성과관리 카드에는 최근 프로젝트가 보입니다.

3

역할 확인

머리글 오른쪽 계정 옆 배지(팀원 / 관리자 · 팀장)로 내 역할을 확인합니다.

새로고침보던 화면에 그대로 머뭅니다. 새 창에서 열면 홈부터 시작합니다.
Chapter 02

연도 고르기

머리글의 「2026 실적관리 ▾」에서 입력할 연도와 지난 연도를 고릅니다.

연도별 1년
과제 입력 · 연도 메뉴
1

연결됨 · 편집

지금 입력하는 연도입니다. 여기서 고친 내용이 이 구글시트 탭에 저장됩니다.

2

보기 전용

지난 연도는 볼 수만 있습니다. 관리자는 연결하기로 그 탭을 입력하는 연도로 바꿀 수 있습니다.

3

새 연도 만들기

지금 연도의 그룹(L1) · 구분(L2) · 열 구성을 이어받거나(완료 안 된 과제만 / 과제 모두 / 구분만) 빈 표로 시작합니다. 만든 연도는 이 브라우저에 저장되고, 관리자가 구글시트로 만들기로 시트에 탭을 만듭니다.

4

목록에서 지우기

쓰지 않는 연도에 마우스를 올리면 ×가 나옵니다. 목록에서만 빠지고 구글시트 탭은 그대로입니다. 메뉴 아래 숨긴 연도 n개 다시 보이기로 되돌립니다.

시트 탭 목록메뉴를 열 때마다 구글시트의 탭 목록을 다시 읽습니다. 시트에서 지운 탭은 목록에서도 빠집니다.
Chapter 03

추진현황 입력하기

그룹(L1) 탭별 일정표에서 과제와 일정을 입력하고 구글시트에 저장합니다.

모두 입력
과제 입력 · 추진현황
1

입력하기

도구 줄의 파란 입력하기를 누르면 입력 모드가 됩니다. 끝나면 입력 끝내기를 누릅니다.

2

칸 선택과 입력

한 번 누르면 선택, 더블클릭하거나 바로 타자를 치면 입력입니다. Enter 반영, Esc 취소. 여러 칸은 끌거나 Shift+클릭으로 고릅니다.

3

서식 막대

칸을 고르면 위에 서식 막대가 뜹니다. 글자색 · 크기 · 굵게 · 기울임 · 취소선 · 정렬 · 병합/나누기를 고른 칸 전체에 적용합니다.

입력 모드 · 서식 막대
분류 · 상태칸을 누르면 칩 목록에서 골라 넣습니다.
채우기고른 칸 오른쪽 아래 점을 끌면 엑셀처럼 반복 입력됩니다.
복사 · 붙여넣기⌘/Ctrl+C ⌘/Ctrl+V. 엑셀 · 구글시트에서 여러 칸을 복사해 와도 됩니다.
우클릭 메뉴행 · 열 추가/삭제, 칸 색, 서식 지우기, 병합 등.
구분(L2) 칸클릭하면 선택, 더블클릭이나 Enter로 이름 고치기. 「이름 [중점]」처럼 쓰면 태그가 붙습니다.
과제 · 그룹 · 열 추가행 번호 아래 파란 + 로 과제, 탭 줄의 그룹 추가로 그룹(L1), 표 끝 + 열로 입력 열을 만듭니다.
Chapter 04

일정 칠하기와 저장

주 칸에 계획과 실적을 칠하면 진척률이 자동으로 계산됩니다.

진척률 기준
1

칠하기 도구 고르기

입력 모드에서 계획(회색) · 실적(분홍) · 지우개를 고르고 주 칸을 누르거나 끌어서 칠합니다. 도구를 우클릭하면 색 팔레트가 열립니다.

2

끝 표시

계획이 끝나는 주에는 F, 실적이 끝나는 주에는 완이 자동으로 찍힙니다.

3

구글시트에 저장

고친 내용은 먼저 이 브라우저에 쌓이고, 구글시트에 저장을 눌러야 시트에 들어갑니다. 되돌리기 ⌘/Ctrl+Z, 다시 하기 ⌘/Ctrl+Shift+Z.

4

엑셀로 받기 · 성과관리로 내보내기

엑셀 아이콘으로 지금 표를 받고, 팀장은 종이비행기 아이콘으로 그룹(L1)을 성과관리 과제리스트로 보냅니다.

저장이 안 되면로그인한 계정이 그 구글시트의 편집자인지 확인하세요. 운영 중인 팀 시트에는 저장하지 않습니다.

Chapter 09

팀원과 피어리뷰

피어리뷰는 팀원별 엑셀 양식을 나눠 주고, 작성한 파일을 받아 올립니다.

엑셀 양식
성과관리 · 팀원관리
1

엑셀 양식 받기

팀원관리 › 피어리뷰에서 엑셀 양식 받기를 누르면 팀원별 양식이 ZIP으로 내려받아집니다. 단순 순위(팀원 전체)와 과제별(함께한 평가과제마다) 중 고릅니다.

2

팀원에게 전달 · 작성

각자 자기 파일에 다른 팀원 순위를 1위부터 겹치지 않게 매기고, 사람마다 순위 근거를 꼭 적어 돌려줍니다.

3

엑셀 올리기

받은 파일을 엑셀 올리기로 한꺼번에 올립니다. 순위가 겹치거나 근거가 빠진 파일은 반영하지 않고 이유를 보여 줍니다.

4

현황 · 결과

응답 현황 n/N명에서 누가 냈는지 보고, 못 받은 사람은 이름을 눌러 직접 입력합니다. 아래에서 평균 순위와 근거를 봅니다.

성과관리 · 피어리뷰
점수 반영피어리뷰를 점수에 넣을지와 비율은 기준설정의 피어리뷰에서 정합니다.

이전 성과 Excel 준비

최근 5년 업적 · 역량 등급을 Excel로 한 번에 올리면 승진 시뮬레이션이 바로 계산됩니다.

5개년 이력
A

승진 시뮬레이션 Excel

회사에서 쓰던 파일 그대로. 시트 하나에 팀원 한 명(시트 이름 = 현재 직급, 예: 과장1).

B

이전 성과 입력 양식

빠른 시작 › 전체 일괄 업로드에서 받는 양식. 한 시트에 모든 팀원의 연도별 줄.

✎

직접 입력

면담 › 성장 시뮬레이션 표에서 연도별 등급을 바로 고를 수도 있습니다.

A. 승진 시뮬레이션 Excel에서 읽는 칸

B3 · C3이름(필수) · 입사일→팀원 연결 · 입사일

1

지난 성과 엑셀파일 불러오기

면담 화면 위쪽 오른쪽의 지난 성과 엑셀파일 불러오기를 누르고 파일을 끌어다 놓습니다.

2

연결 확인

파일의 이름과 똑같은 이름의 팀원에게만 연결됩니다(새 팀원은 만들지 않음). 동명이인은 목록에서 직접 고르고, 매칭 안 된 사람은 건너뜁니다.

승진 시뮬레이션

팀원별로 목표 점수 대비 지금 점수와 심사 때 기대 점수를 보고, 등급을 바꿔 보며 시뮬레이션합니다.

면담 준비
성과관리 · 면담 · 성장 시뮬레이션
1

팀원 고르고 직급 · 심사 시기 정하기

면담 화면 위 탭에서 팀원을 고릅니다. 이름 옆 직급과 승진심사(연도 · 4월 정기 / 9월 특별)를 정합니다. 심사 시기가 없으면 체류연한으로 추정합니다.

2

점수 카드 보기

목표 점수(다음 직급 승진자격점수), 현재 점수 + 심사까지 예상 변화, 최종 기대 점수(+N점 충족 / -N점 필요)를 봅니다. 목표 이상이면 탭에 승진 가능이 붙습니다.

3

성장 시뮬레이션 펼치기

왼쪽 세로 막대 성장 시뮬레이션을 누르면 연도별 업적(상) · 업적(하) · 역량 표가 열립니다. 등급을 바꾸면 바로 저장되고 점수가 다시 계산됩니다. 기록이 없는 해는 평년 실적으로 채운 예상 값이 회색으로 보입니다.

4

보조지표

직책 · 상벌 · 체류 · 교육 점수를 넣으면 합계에 더해집니다.

5

승진 기준 보기 · 고치기

기준 보기를 누르면 직급별 체류연한 · 승진자격점수, 등급 점수, 연차별 가중치가 보입니다. 수정하기로 체류연한 · 승진자격점수 · 등급 점수를 바꿀 수 있습니다(가중치는 고정).

자주 묻는 질문

막혔을 때 먼저 확인하세요.

구글시트에서 탭을 지웠는데 연도 목록에 남아 있어요.

연도 메뉴를 다시 열면 시트 목록을 새로 읽어 빠집니다. 탭은 남겨 두고 목록에서만 빼려면 그 연도의 ×를 누르세요.

화면이 하얗게 나와요.

새 버전이 올라온 직후일 수 있습니다. ⌘/Ctrl+Shift+R로 강력 새로고침하세요.

구글 로그인 창에 「400 · That’s an error」가 떠요.

브라우저에 구글 계정이 여러 개 로그인돼 있을 때 생깁니다. 안내 아래 계정 골라서 다시 연결을 눌러 계정을 직접 고르세요.

저장하면 편집 권한이 없다고 나와요.

로그인한 계정이 그 구글시트의 편집자가 아닙니다. 시트 소유자에게 편집 권한을 요청하세요.

성과관리가 안 보여요.

성과관리는 팀장 계정에만 보입니다. 계정 옆 배지가 「팀원」이면 과제 입력만 쓸 수 있습니다.

성과관리를 초기화했는데 과제 입력에 예전 표가 보여요.

두 영역의 데이터는 따로 저장됩니다. 초기화할 때 「과제 입력 데이터도 같이 지우기」를 체크하세요.

검색 결과가 없습니다.
