페이스 개인정보처리방침

시행일 2026년 9월 29일

페이스(과제관리, 이하 "앱")는 디자인연구소 구성원이 추진현황을 입력하고 팀장이 성과를 관리하기 위해 쓰는 내부용 웹 앱입니다. 이 문서는 앱이 어떤 정보를 어떻게 다루는지 설명합니다.

1. 앱의 구조

앱에는 별도의 서버가 없습니다. 앱은 사용자의 브라우저에서만 동작하며, 사용자가 로그인한 Google 계정으로 Google API에 직접 요청합니다. 앱 개발자나 운영자가 사용자의 데이터를 따로 받아 저장하는 곳은 없습니다.

2. 요청하는 Google 권한과 쓰는 곳

권한쓰는 곳
이메일 주소
userinfo.email		로그인한 계정을 알아보고, 권한 관리 시트에서 그 계정의 역할(관리자, 팀장, 팀원)을 찾는 데 씁니다.
Google 스프레드시트
spreadsheets		사용자가 열 수 있도록 공유받은 추진현황 시트와 권한 관리 시트를 읽고, 사용자가 입력한 내용과 진척률 표를 그 시트에 저장합니다. 사용자가 연결하지 않은 시트는 열지 않습니다.
Google 드라이브(앱이 만든 파일만)
drive.file		성과관리 데이터 백업 파일을 사용자의 드라이브에 저장하고 불러옵니다. 앱이 만들거나 사용자가 앱에서 고른 파일 외의 드라이브 파일은 볼 수 없습니다.
Google 캘린더
calendar		팀장이 면담 일정을 등록할 때, 앱 전용 캘린더를 만들고 그 캘린더의 일정을 만들거나 고치거나 지웁니다.
Gmail 보내기
gmail.send		팀장, 관리자가 팀원 초대 메일을 보낼 때만 요청합니다. 초대 메일을 보내는 데만 쓰며, 받은편지함이나 다른 메일은 읽지 않습니다.

3. 저장되는 곳

  • 사용자의 브라우저: 로그인 상태, 화면 설정, 입력 중인 내용, 성과관리 데이터가 이 브라우저의 저장공간에 남습니다.
  • 사용자의 Google 계정: 사용자가 저장을 누른 내용은 공유받은 Google 스프레드시트에, 백업은 사용자의 Google 드라이브에, 면담 일정은 사용자의 Google 캘린더에 저장됩니다.
  • 앱 개발자, 운영자, 그 밖의 제3자에게 데이터를 보내거나 판매하지 않으며, 광고에 쓰지 않습니다.

4. 누가 볼 수 있나

시트의 내용은 그 시트를 공유받은 사람만 볼 수 있습니다. 앱 안의 역할 구분(관리자, 팀장, 팀원)은 메뉴를 나누는 용도이며, 실제 열람 권한은 Google 스프레드시트의 공유 설정이 정합니다.

5. Google API 데이터 사용

앱이 Google API로 받은 정보를 사용하고 다른 앱으로 옮기는 방식은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다.

6. 데이터 지우기와 권한 해제

  • 브라우저에 남은 데이터: 앱의 데이터 백업 메뉴에서 초기화하거나, 브라우저에서 이 사이트의 데이터를 지웁니다.
  • Google 계정에 저장된 내용: 해당 스프레드시트, 드라이브 파일, 캘린더에서 직접 지웁니다.
  • 앱에 준 권한: Google 계정 › 타사 앱 및 서비스에서 언제든 해제할 수 있습니다.
