# 과제관리·팀원관리 기능 이식 프롬프트

다른 앱의 Claude Code 세션에 아래 "프롬프트" 부분을 그대로 붙여 넣는다.
`{대상 앱}`, `{작업 브랜치}`처럼 중괄호로 된 곳만 바꾼다.

---

## 프롬프트

이 앱({대상 앱})에 "과제관리(과제리스트 · 평가과제)"와 "팀원관리" 기능을 옮겨 오려고 합니다.
원본은 GitHub `kukkkuku/desktop-tutorial` 저장소의 `feature/next-2026-09-24` 브랜치입니다
(React 18 + TypeScript + Vite + Tailwind 3). 코드를 그대로 복사하기보다, 이 앱의 구조·데이터 모델·
스타일에 맞게 **동작과 사용성**을 옮기는 것이 목표입니다.

### 진행 방식
1. 먼저 이 앱의 구조(스택, 상태 관리, 데이터 저장, 기존 과제/팀원 관련 화면, 디자인 토큰)를 파악하고,
   원본 저장소의 아래 "참고 파일"을 읽은 뒤 **이식 계획**을 먼저 보여 주세요. 계획에는
   ① 그대로 가져올 것 ② 이 앱에 맞게 바꿀 것 ③ 이 앱에 없어서 뺄 것(예: 구글시트 연동)을 나눠 적습니다.
   제가 확인한 뒤 구현을 시작합니다.
2. 작업은 `{작업 브랜치}`에서만 하고, 운영 브랜치(main 등)에는 푸시하지 마세요.
3. 단계마다 타입 검사·빌드를 통과시키고, 브라우저(Playwright 등)로 화면을 직접 띄워 확인한 뒤 커밋하세요.
   확인하지 못한 것은 확인하지 못했다고 보고해 주세요.
4. **값을 지어내지 마세요.** 사람이 입력한 값과 앱이 채운 기본값을 구분합니다
   (원본 `docs/DATA-MODEL.md`). 예: 성과등급을 안 매긴 과제는 'B'로 채우지 않고 "미입력"(null)으로 두고 점수에서 뺍니다.
5. 실제 업무 데이터 파일(엑셀 등)은 커밋하지 마세요.

### 1. 메뉴 구성
- 상단 메뉴 **과제관리** 하나 안에 세그먼트 탭 **과제리스트 | 평가과제**.
- 상단 메뉴 **팀원관리** 안에 **팀원 | 피어리뷰**(피어리뷰는 이번 범위가 아니면 빼도 됨).

### 2. 공통 표(DataGrid) — 엑셀처럼 쓰는 편집 표
세 화면(과제리스트·평가과제·팀원) 모두 같은 표 컴포넌트를 씁니다. 표는 데이터를 들고 있지 않고
바뀐 내용을 콜백으로 부모에 알립니다(부모가 새 데이터를 내려주고, 되돌리기도 부모가 스냅샷으로).

- **선택**: 칸 클릭 = 선택, 드래그/Shift = 범위. 선택 범위는 **하나의 파란 테두리 상자**로 보이고,
  행 선택은 번호 칸부터, 열 선택은 머리글부터 한 덩어리로 감쌉니다. 표 밖 빈 곳을 누르면 선택 해제.
- **입력**: 선택 상태에서 바로 타이핑하면 덮어쓰기. Enter/F2/더블클릭 = 이어서 편집, Alt+Enter = 칸 안 줄바꿈,
  Esc = 취소, 화살표·Tab 이동. 한글 IME가 깨지지 않도록 활성 칸 위에 **투명 textarea**를 두고 포커스를 유지합니다
  (첫 글자를 keydown에서 가로채지 않음). 이 textarea에는 전역 입력칸 포커스 링이 보이지 않게 합니다.
- **복사·붙여넣기**: 엑셀/구글시트의 TSV(따옴표로 감싼 칸 안 줄바꿈·탭 포함)를 그대로 붙여넣기. 행이 모자라면 부모가 행을 늘림.
- **행**: 표 아래 "+ 추가"(화면마다 이름 다름), 우클릭 메뉴(위/아래에 추가, 위/아래로 이동, 내용 지우기, 삭제),
  번호 칸을 잡고 끌어서 이동(노션처럼 **고스트**가 커서를 따라가고 삽입 위치에 선 표시), ⌥↑/↓ 이동, Delete로 삭제.
- **열**(과제리스트만): 머리글 두 번 눌러 이름 바꾸기, 폭 조절, 끌어서 순서 변경, 우클릭(왼쪽/오른쪽 열 추가, 숨기기, 삭제).
  시트에서 온 열은 삭제 대신 숨기기만. **설정 아이콘** 하나로 "표시할 열" 체크 목록(맨 위에 "번호" 표시 여부).
- **번호 칸**: 폭 조절(브라우저에 기억). 번호를 숨기면 번호 칸 자체를 없애고, 체크 칸이 행 선택·끌기·우클릭을 대신합니다.
- **선택형 칸**(상태·분류·직급 등): 칸에는 색 칩 + ▾. 누르면 표 밖에 **칩 목록 팝업**.
  하나만 고르는 칸은 찾기 입력칸·안내 문구 없이 칩만. 여러 개 고르는 칸(담당자)과 새 값을 넣을 수 있는 칸은 찾기 입력 + "완료".
- **날짜 칸**: 앱 공통 달력 하나(오늘/내일/지우기, 제목을 누르면 날짜→월→연도). 직접 입력(2026-05-14, 2026.5.14)도 됨.
- **옵션**: `fixedColumns`(열 추가·삭제·이름 변경 끔), 칸별 `readOnly`(계산 값), `rowDetail`(행 아래 펼침 내용),
  `onInsertRows` 없으면 행 추가 숨김, `groupHeaders`(묶음 머리 행), `check`(행 앞 체크박스), `rowNumber`, `storageKey`.
- **되돌리기**: ⌘Z / ⌘⇧Z(또는 ⌘Y)를 표뿐 아니라 화면 전체에서. 머리 오른쪽에 되돌리기·다시하기 아이콘.

### 3. 과제리스트 (그룹 → 과제 2단계)
- **그룹(L2) 탭**: 폴더 탭 모양, 탭 오른쪽 끝 "+ 그룹 추가"(새 이름 "새 그룹 N", 바로 이름 편집).
  탭의 X → 확인창("과제 삭제" 식으로 구체적인 제목, 문장은 줄바꿔 읽기 쉽게) → 앱에서만 삭제(원본 시트는 그대로).
  확인창에 **이 그룹에만 담당자로 있는 팀원도 함께 삭제** 체크 목록(기본 꺼짐; 다른 곳에서 쓰이는 팀원은 이유와 함께 비활성).
- **행을 다른 그룹 탭으로 끌어 옮기기**: 탭 위에 올리면 고스트에 "+ → 그룹명". 옮긴 탭에 가면 옮겨 온 행에
  연한 주황 배경(다른 곳을 누르면 사라짐) + 과제명 옆 주황 점(잠시 뒤 사라짐).
  묶음 하위 과제 일부만 옮기면 그 과제는 묶음에서 빠져 낱개로 옮겨집니다(묶음 전체를 옮길 때만 묶음 유지).
- **구글시트 연동**(이 앱에 없으면 제외 가능): 탭 줄 오른쪽 끝에 시트 아이콘 + 시트 이름 + "n분 전" 배지 +
  새로고침 아이콘(툴팁 "다시 가져오기"). 계정 메뉴에 "구글시트 과제로 이동" 링크.
  다시 가져오기 때 앱에서 고친 칸(editedAt)은 덮지 않고, 시트에서 사라진 행은 지우지 않고 주황 점으로 표시,
  앱에서 지운 시트 행은 다시 살리지 않음(excludedSheetKeys).
- **자동 규칙**: 완료일을 넣으면 상태를 "완료"로.
- **묶음(평가과제 단위로 묶기)**:
  - 여러 행 선택 → 우클릭 "평가과제로 묶기"(이름 자동 "첫 과제명 외 N건") / "묶음 풀기".
  - 묶음 머리 행: **흰 배경**, 굵은 이름, 크고 잘 보이는 접기 화살표. 이름은 두 번 눌러 바꾸기.
    분류 칸은 개별 행과 같은 칩 + 칩 목록 → 고르면 하위 과제 전체의 분류가 바뀌고 이미 내보낸 평가과제의 과제등급도 맞춤.
    상태 칸은 "완료 n/m", 담당자는 하위 담당자 합집합, 시작일·완료일은 요약. 호버 시 "묶음 풀기" 아이콘.
  - 하위 행: **연회색 배경** + 들여쓰기 + ↳ 아이콘, 호버 시 "묶음에서 빼기" 아이콘. 왼쪽 세로선이나 파란 점 같은 표식은 쓰지 않음.
  - 번호: 묶음 1, 하위 1-1, 1-2 …(접었다 펴도 헷갈리지 않게).
  - 접힌 묶음도 번호 칸을 눌러 선택, Shift/⌘로 여러 묶음 선택, 끌어서 묶음째 이동. 하위 행을 다른 묶음으로 끌어 옮기기.
  - 이미 평가과제로 내보낸 묶음도 풀기·옮기기가 됩니다(묶음은 보기용, 평가과제 연결은 그대로).
- **평가과제로 내보내기**: 행(또는 묶음)을 체크 → 체크 옆에 뜨는 "평가과제로 내보내기".
  묶음 하나 = 평가과제 하나, 낱개 L3 하나 = 평가과제 하나. 분류가 섞여 과제등급을 정할 수 없으면 주황 테두리로 선택을 요구.
  내보낸 행은 체크 비활성 + 묶음 머리에 "내보냄" 배지.

### 4. 평가과제 (과제리스트에서만 생성)
- 여기서 직접 추가하지 않습니다(출처를 하나로). 비어 있으면 "과제리스트로 이동" 안내.
- 같은 DataGrid(`fixedColumns`): 과제명 · 과제등급(칩) · 성과등급(칩, 미입력 허용) · 목표 · 성과 · 점수(읽기 전용) · 참여(읽기 전용).
  이름은 비울 수 없고 중복 불가 → 해당 칸만 건너뛰고 표 위에 빨간 한 줄 안내.
- 행 삭제: 확인창(과제 이름 목록 + "평가 데이터도 함께 지워집니다 · 과제리스트의 L3는 그대로 · ⌘Z로 되돌릴 수 있음").
- 과제명 앞 화살표로 **아코디언**: 연결된 L3 목록을 선 없는 표처럼 열 정렬(그룹 · 과제 · 상태 · 담당자 · 기간, 위에 작은 열 제목).
  "L3 n건 묶음" 같은 배지는 쓰지 않음.

### 5. 팀원관리
- 상단 추가 폼 없음. 같은 DataGrid(`fixedColumns`):
  이름 · 입사일(달력) · 근속(자동, 읽기 전용) · 직급(칩) · 직급 발령일(달력) · 직급 연차(자동) · 역할 · 담당팀(칩, 새 값 입력 가능) ·
  이메일 · 상태(활성/비활성 칩) · 담당 L3 수 · 평가과제 수 · 받은 피어리뷰("n건 확인" 버튼).
- 표 아래 "+ 팀원 추가" → "새 팀원"(겹치면 "새 팀원 2") 행이 생기고 이름 칸이 선택돼 바로 타이핑.
  엑셀에서 여러 줄을 붙여넣으면 모자란 만큼 팀원 추가. 이름 필수·중복 불가, 날짜로 못 읽는 값은 건너뛰고 안내.
- 이름 칸 호버 시 아이콘 → 팀원 상세 열기.
- 삭제: 행 선택 후 Delete/우클릭 → 확인창(이름 목록 + 기여도·피어리뷰·면담 기록도 삭제 · 과제의 담당자 표시는 이름만 남음 · ⌘Z).
  되돌리기는 삭제가 딸린 데이터까지 지우므로 **앱 상태 전체 스냅샷**으로 합니다(원본 `useStateHistory`).
- 과제 담당자 중 팀원 목록에 없는 사람: 평소엔 "› 과제 담당자 중 팀원 목록에 없는 사람 N명 · 눌러서 추가" 한 줄로 접어 두고,
  펼치면 이름 칩(담당팀 · L3 수)을 골라 "선택한 N명 추가". 추가하면 과제 담당자와 자동 연결.

### 6. 디자인 (macOS 스타일, 한 가지 규칙)
- 이 앱에 디자인 시스템이 있으면 그것을 따르고, 없으면 원본 `docs/DESIGN-SYSTEM.md` 규칙을 가져옵니다:
  강조색 #007AFF 하나, 글자 3단계(label/label-2/label-3), 모서리·그림자 토큰, 아이콘은 lucide-react 한 벌(16/14/18, 선 1.75),
  버튼 4종(primary·secondary·ghost·danger) 2크기, 탭·보기 전환은 세그먼트 컨트롤, 팝오버·메뉴·확인창 한 모양, 달력 하나.
- 색 코드·임의 그림자를 화면 코드에 직접 쓰지 않고 토큰만 씁니다. 긴 설명 문단 대신 한 줄 안내.
