# 매뉴얼에 반영할 내용 (모아 두었다가 한 번에)

사용자가 "매뉴얼 수정하자"고 할 때 한 번에 반영한다. 반영한 항목은 지운다.
앱 기능을 바꿀 때마다 여기에 한 줄씩 추가한다(매뉴얼은 그때그때 고치지 않음).

## 대기 중

- [ ] 성과관리 › 평가 목록 › 팀 이름 바꾸기: 바꾼 뒤 「관리의 팀 이름도 바꿀까요?」 창이 뜬다(바뀌는 사람 목록 · 「관리에도 적용」 / 취소). 관리자는 그 팀 전체, 팀장은 본인과 본인이 추가한 팀원만.
- [ ] 관리 › 팀원 · 권한: 팀 이름이 평가 목록과 다르면 위에 안내 줄 → 「「평가 목록 이름」로 맞추기」 / 「「관리 이름」로 맞추기」 중 고름. 관리 이름을 고르면 평가 목록의 그 팀 평가 · 팀원 담당팀과 내가 추가한 팀원 팀도 바뀜.
- [ ] 과제 입력: 초대 메일의 「페이스 시작하기」 링크로 들어오면 과제 시트를 기억한다(팀원은 권한 시트 없이도 과제 시트가 열림). 과제 시트를 바꾸면 팀원에게 초대 메일을 다시 보내야 함 -- 과제 입력 매뉴얼 1장(관리자가 공유한 시트)에도 한 줄.
- [ ] 관리 탭 구성 변경: 「팀원 · 권한」(팀장은 「팀원」) / 「실적관리 시트」(1 · 시트 연결 — 관리자만 바꾸기, 2 · 공유 — 팀장 · 팀원 편집자, 팀장은 내가 추가한 팀원만) / 「권한 시트」(관리자만 — 시트 정보 · 관리자 · 팀장에게 편집자 공유, 팀원은 공유 안 함). 지금 매뉴얼의 「구글 시트」 탭 설명 · 그림(admin-task.png)을 이 구성으로 바꾸고 권한 시트 그림 추가.
- [ ] 추진현황 상태줄: 버튼 이름 「최신 내용 받기」 → 「최신으로 업데이트」, 「그 뒤 저장된 내용은 아직 안 받음」 문구는 없어짐(버튼만). 매뉴얼에서 「최신 내용 받기」 찾아 모두 바꾸기.
- [ ] 추진현황 저장 → 시트의 숨김 탭 「변경 기록」에 한 줄씩 남음(시각 · 누가 · 연도 탭 · 과제 · 바꾼 칸 · 이전 값 · 새 값, 새 과제 · 삭제(지운 내용) · 줄 옮김 · 열 추가/삭제 · 구분 이름도). 보는 법: 시트 [보기] → [숨겨진 시트] → 변경 기록. 시트 전체 되돌리기는 [파일] → [버전 기록].
- [ ] 추진현황 저장 창: 제목 「구글시트에 업데이트」, 「N건의 변경이 있습니다. 구글 시트에 업데이트하여 공유하시겠습니까?」 [나중에] [지금 업데이트], 「업데이트할 곳」. 매뉴얼의 저장 창 설명 · 그림 바꾸기.
- [ ] 저장 창 「다음부터 묻지 않고 바로 업데이트」 체크 → 입력 끝내기 · 저장 때 바로 업데이트(과제 삭제가 있으면 늘 물음). 다시 켜기: 파일 메뉴 › 「업데이트 전에 묻기」. 업데이트 때마다 시트를 새로 읽어 그사이 남이 바꾼 칸은 덮지 않음.
- [ ] 추진현황 탭 줄 오른쪽 「숨긴 그룹」 버튼이 눈 아이콘 + 숫자만(숨긴 게 없으면 아이콘만). 매뉴얼의 「숨긴 그룹 N」 · 「그룹 숨기기」 표현 바꾸기.
- [ ] 추진현황 그룹 고르기 목록: 체크박스 대신 눈 아이콘(파란 뜬 눈 = 보임, 연한 회색 감은 눈 = 숨김). 매뉴얼 설명 · 그림 바꾸기.
- [ ] 관리 › 팀원(팀장): 내가 추가한 사람 + 우리 팀(평가 목록 팀 이름 · 내 팀) 팀원이 보임. 평가 목록 팀원 중 명단에 없는 사람이 있으면 「평가 목록 팀원 불러오기」(Gmail 빈 줄은 채워서 추가). 이미 등록된 사람을 추가하면 어느 팀 · 누가 추가했는지 안내.
- [ ] 성과관리 › 팀원관리: 「활성」 스위치가 켬/끔 뱃지로(파란 「활성」 / 회색 「비활성」, 눌러서 전환). 그림 바꾸기.
- [ ] 관리 › 팀원: 화면을 열면 평가 목록(성과관리) 팀원 중 명단에 없는 사람을 묻지 않고 자동으로 명단에 추가(버튼 없음, 목록에서 뺀 사람은 다시 불러오지 않음) → 이름으로 바로 명단에 추가(Gmail을 아는 사람은 Gmail까지). Gmail이 없는 사람은 계정 칸에 「Gmail 입력」이 뜨고 아이디만 적어도 @gmail.com으로 저장. Gmail이 없는 동안은 초대 메일 · 시트 공유 목록에서 빠짐.
- [ ] 추진현황: 저장 안 한 변경이 있는 그룹(L1) 탭 이름 앞에 주황 점(상태줄의 「저장 안 한 변경 N건」과 같은 색).
- [ ] 팀 이동(새 장 또는 관리 장에 한 절): ① 관리자나 이전 팀장이 관리 › 팀원에서 팀 칸을 새 팀으로 → 이전 팀장 목록에서 빠지고 새 팀장 목록에 보임(팀장 화면은 팀 칸 기준, 팀이 비어 있으면 내가 추가한 사람) ② 이전 팀장 성과관리 › 팀원관리에 「다른 팀으로 옮긴 팀원 N명」 → 「의견 남기고 비활성」(맡았던 과제 · 기여도 자동 + 의견, 권한 시트 숨김 탭 「인수인계」에 저장, 팀원 본인은 못 봄) ③ 새 팀장 팀원관리 「관리에 새 팀원」으로 불러오면 이름 옆 💬 → 이전 팀장 의견 · 과제 보기. 평가는 새 팀장이.
- [ ] 추진현황 그룹 탭: 저장 안 한 변경 주황 점은 과제 수 오른쪽 위(탭이 좁으면 이름 오른쪽 위), 과제가 늘거나 줄면 과제 수도 주황 굵게.
- [ ] (참고) 오류 안내 문구가 한국어로 바뀜 -- 매뉴얼의 문제 해결(FAQ)에 영어 오류 예시가 있으면 새 문구로: 「○○ 권한이 없습니다. 공유받은 계정으로 로그인했는지 확인해 주세요」 · 「구글 로그인이 만료되었습니다」 · 「구글 요청이 많아 잠시 막혔습니다」 · 「구글 시트 연결이 아직 준비되지 않았습니다. 앱 관리자에게 알려 주세요」.
- [ ] 추진현황 찾기 칸 · 관리 › 팀원 찾기 칸: 글자가 있으면 오른쪽에 ✕(지우기). Esc로도 지움.
- [ ] 추진현황 상태줄: 「다시 불러오기」가 오른쪽 끝 글자 버튼에서 「최신 · ○분 전 확인」 바로 뒤 ↻ 아이콘으로(툴팁 「다시 불러오기」).
- [ ] 관리 › 팀원: 「받는 메일 열」 체크박스가 계정(Gmail) 머리글 옆 +✉ 아이콘 버튼으로(누르면 e-mail(받는 메일) 열이 생기고 파랗게, 다시 누르면 숨김). 매뉴얼 4단계 「받는 메일 열을 켜고」 문구 · 그림 바꾸기.
- [ ] 관리 › 팀원 추가 › 「추진현황 담당자에서 가져오기」: 담당팀이 팀 칸과 같은 과제의 담당자 중 명단에 없는 사람을 많이 맡은 순으로(없으면 모든 팀, 「모든 팀」 체크로 전체) → 골라 「선택한 N명 추가」, 이름만 들어가고 Gmail은 표에서. 추진현황을 한 번 불러온 뒤에 보임.
- [ ] 홈 › 과제 입력 카드: 「지금 연도 / 시트」 항목 이름이 없어지고 「2026 실적관리 · 과제 N건」 / (시트 아이콘) 시트 파일 이름(운영 시트면 「읽기 전용」) 두 줄. 「테스트 시트」 표현 없어짐. 홈 그림 바꾸기.
- [ ] 추진현황 편집 1단계: 여러 칸을 고르면 범위 바깥이 파란 테두리(안은 옅은 파랑) · 구분(L2) 이름 고치기 상자가 다른 칸과 같은 네모 · 구분 칸을 고르면 위 서식 막대로 굵게 · 색 · 크기 · 정렬 · Tab/Shift+Tab이 표 안에서만 이동(구분 칸 Tab → 그 구분 첫 과제, 일정 칸도 Tab 이동).
- [ ] 추진현황 편집 2단계(서식 단위): 칸(클릭 · 끌기) / 행(행 번호 클릭, Shift로 여러 행) / 열(머리글 클릭 = 지금 탭의 그 열 전체, 거른 행 · 새 과제 포함 · 다른 탭은 그대로) / 전체(모서리 칸) / 구분(L2 칸을 누르면 그 구분의 행 전체 + 구분 칸)을 고르고 같은 서식 막대로: 글자 색 · 칸 색(새) · 크기 · B/I/S · 정렬 · 병합(서식 지우기 버튼은 없앰). 나중에 바꾼 서식이 이김. 새로 넣는 행은 기준 행의 글자 서식을 이어받음.
- [ ] 추진현황 편집 3단계: 칸 우클릭 메뉴 순서 = 잘라내기 · 복사 · 붙여넣기 / 메모 / 행 · 열 · 셀 삽입 / 행 · 열 삭제 / 굵게 · 글자 색 · 칸 색. 행 번호 우클릭 → 「행 복제」(값 · 칸 색 · 서식 그대로 바로 아래). 과제(L3) 머리글을 누르면 L3 열 전체 선택.
- [ ] 추진현황 머리글 · 서식 막대: 서식 막대는 툴바가 아니라 고른 칸 · 범위 · 행 · 열 · 구분 바로 위에 뜬다(입력하기 중). 칸: 클릭 = 선택, 더블클릭 = 글씨 편집, 우클릭 = 메뉴. 열 머리글: 클릭 = 열 선택(머리글까지 파란 테두리), 더블클릭 = 제목 편집(이름 · 글자 색 · 크기 · 정렬 -- 이름은 새로 넣은 열 · 앱이 모르는 열만, 상태 · 담당자 같은 기본 열은 이름 고정), 우클릭 = 머리글 배경 · 머리글 글자 색(+ 열 삽입 · 삭제 · 숨기기). 머리글 글자 서식 · 색은 이 브라우저에 기억, 열 이름은 저장하면 시트 머리글에.
