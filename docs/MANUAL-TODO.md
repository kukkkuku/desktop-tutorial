# 매뉴얼에 반영할 내용 (모아 두었다가 한 번에)

사용자가 "매뉴얼 수정하자"고 할 때 한 번에 반영한다. 반영한 항목은 지운다.
앱 기능을 바꿀 때마다 여기에 한 줄씩 추가한다(매뉴얼은 그때그때 고치지 않음).

## 대기 중

- [ ] 성과관리 › 평가 목록 › 팀 이름 바꾸기: 바꾼 뒤 「관리의 팀 이름도 바꿀까요?」 창이 뜬다(바뀌는 사람 목록 · 「관리에도 적용」 / 취소). 관리자는 그 팀 전체, 팀장은 본인과 본인이 추가한 팀원만.
- [ ] 관리 › 팀원 · 권한: 팀 이름이 평가 목록과 다르면 위에 안내 줄 → 「「평가 목록 이름」로 맞추기」 / 「「관리 이름」로 맞추기」 중 고름. 관리 이름을 고르면 평가 목록의 그 팀 평가 · 팀원 담당팀과 내가 추가한 팀원 팀도 바뀜.
- [ ] 과제 입력: 초대 메일의 「페이스 시작하기」 링크로 들어오면 과제 시트를 기억한다(팀원은 권한 시트 없이도 과제 시트가 열림). 과제 시트를 바꾸면 팀원에게 초대 메일을 다시 보내야 함 -- 과제 입력 매뉴얼 1장(관리자가 공유한 시트)에도 한 줄.
- [ ] 관리 탭 구성 변경: 「팀원 · 권한」(팀장은 「팀원」) / 「실적관리 시트」(1 · 시트 연결 — 관리자만 바꾸기, 2 · 공유 — 팀장 · 팀원 편집자, 팀장은 내가 추가한 팀원만) / 「권한 시트」(관리자만 — 시트 정보 · 관리자 · 팀장에게 편집자 공유, 팀원은 공유 안 함). 지금 매뉴얼의 「구글 시트」 탭 설명 · 그림(admin-task.png)을 이 구성으로 바꾸고 권한 시트 그림 추가.
- [ ] 추진현황 상태줄: 버튼 이름 「최신 내용 받기」 → 「최신으로 업데이트」, 「그 뒤 저장된 내용은 아직 안 받음」 문구는 없어짐(버튼만). 매뉴얼에서 「최신 내용 받기」 찾아 모두 바꾸기.
- [ ] 추진현황 저장 → 시트의 숨김 탭 「변경 기록」에 한 줄씩 남음(시각 · 누가 · 연도 탭 · 과제 · 바꾼 칸 · 이전 값 · 새 값, 새 과제 · 삭제(지운 내용) · 줄 옮김 · 열 추가/삭제 · 구분 이름도). 보는 법: 시트 [보기] → [숨겨진 시트] → 변경 기록. 시트 전체 되돌리기는 [파일] → [버전 기록].
- [ ] 추진현황 저장 창: 제목 「구글시트에 업데이트」, 「N건의 변경이 있습니다. 구글 시트에 업데이트하여 공유하시겠습니까?」 [나중에] [지금 업데이트], 「업데이트할 곳」. 매뉴얼의 저장 창 설명 · 그림 바꾸기.
- [ ] 저장 창 「다음부터 묻지 않고 바로 업데이트」 체크 → 입력 끝내기 · 저장 때 바로 업데이트(과제 삭제가 있으면 늘 물음). 다시 켜기: 파일 메뉴 › 「업데이트 전에 묻기」. 업데이트 때마다 시트를 새로 읽어 그사이 남이 바꾼 칸은 덮지 않음.
