# 매뉴얼에 반영할 내용 (모아 두었다가 한 번에)

사용자가 "매뉴얼 수정하자"고 할 때 한 번에 반영한다. 반영한 항목은 지운다.
앱 기능을 바꿀 때마다 여기에 한 줄씩 추가한다(매뉴얼은 그때그때 고치지 않음).

## 대기 중

- [ ] 글 반영은 2026-10-11에 모두 끝냄(`docs/manual-src/chapters3.py`). 아래 「그림 교체」만 남음.

## 그림 교체(가짜 데이터로 새로 찍어야 함 -- 글은 이미 바뀌었고 그림만 옛 모양)

- [ ] 홈(`home.png`) · 계정 메뉴 · 사이드바가 보이는 모든 전체 화면 캡처: 기본 디자인(푸른 회색 바탕 · 검정 버튼 · 파란 선택), 사이드바 폭 200px · 계정 버튼 아래, 평가 목록 · 과제관리 · 면담 탭 모양.
- [ ] 관리: `admin-members.png`(권한 설정 전면 개편: 팀별 묶음 표 · 검정 줄 · 한 줄 도구) · `admin-task.png`(실적관리 시트 · 권한 시트 한 줄) 새로.
- [ ] 평가 목록(`projects.png`): 팀 탭 · 연도 탭 · 카드(평가과제 목록 · 아바타 줄 · 평가 계속하기) · 팀원 초대 창(왼쪽 보낼 메일 · 오른쪽 초대할 사람).
- [ ] 추진현황 계열(`progress.png` · `edit.png` · `unsaved-bar.png` · `xlsx-bar.png` · `year-menu.png` · `board.png` · `timeline.png`): 머리 줄(시트 › 탭 ⌄ · 최신 · ↻), 눈 아이콘 숨긴 그룹 버튼, 필터 줄, 서식 막대, 저장 창(구글시트에 업데이트).
- [ ] 과제 보내기/가져오기 화면(`import.png`): 한 화면(분류 전체 선택 · 두 줄 목록 · 선택 칩 · 추가할 팀원 · 보낼 곳 · 취소 · N건 보내기)과 평가가 없을 때의 작은 창.
- [ ] 과제관리(`tasklist.png` · `eval-only.png`): 평가 대상만 · 평가하기 버튼 · 성과등급/목표 열 외곽선 · ⌘ 클릭 선택 · 묶음 담당자 ＋ .
- [ ] 팀원관리(`members.png`): 도구 줄 · 활성 배지 · Gmail 아이디 + 초대 칸 · 근속.
- [ ] 평가하기(`eval.png`): 가로 · 세로 바꾸기 아이콘 · 팀원이 행인 보기.
- [ ] 평가결과(`results.png`): 전체/팀원 칩 · 과제별 성과 표 · 상태 단추 · 리포트 다운로드 메뉴.
- [ ] 면담(`meeting.png` · `notes.png`): 왼쪽 면담 기록 라인(막대 + 마우스 올린 미리보기) · 입력 열 순서 · 네 칸 접기.
- [ ] 초대 메일(`invite.png`) · 데이터 초기화(`reset.png`, 계정 메뉴 › 데이터 초기화…) · 데이터 백업 창 · 테마 고르는 화면(기본 디자인 · 오렌지 · 블랙 · 블루 포인트).
- [ ] 로그인 화면: 초대받은 계정 · 이 계정으로 계속.
- [ ] 로그인 화면 그림 교체(왼쪽 일러스트 + 오른쪽 로그인, 초대받은 계정 · 이 계정으로 계속 포함)
